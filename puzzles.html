Puzzle Solutions

The Three Locks

Found in the Lake Sanctuary. Each lock requires a different memory to open.

Lock 1: "The memory of laughter" - Stand on the left lily pad

Lock 2: "The memory of rain" - Wait for rain, then touch the door

Lock 3: "The memory of home" - Look at the painting, then touch the heart symbol

Forest Maze

The shifting paths can be confusing. Here's the correct route:

Start → Left → Left → Right → Straight → Right → Left → Clear

Alternative: Follow the sound of water - it always leads to the exit.

Mountain Wind Currents

Use the wind patterns to climb efficiently:

  • Wind blows east every 30 seconds - use it to jump to eastern ledges
  • When wind turns red, take cover behind rocks
  • The strongest current appears at sunset - climb the north face then

Memory Sequence Puzzle

In the Summit Temple, arrange the memories in chronological order:

Correct order: 🌅 → 🌾 → 🎉 → 🌧️ → ❄️ → 🌸 → ⭐

Morning → Harvest → Celebration → Rain → Snow → Cherry Blossoms → Stars

The Final Choice

No puzzle here - just a reflection. Each option leads to a different ending:

  • Embrace - Place all memories in the basin
  • Let Go - Return memories to the wind
  • Hold On - Keep one memory and return the rest
